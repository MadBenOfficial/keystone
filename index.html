02

The Strategist decomposes the objective into four to eight milestones with prerequisite edges. Validators independently re-run it and must agree on the feasibility reading before it commits.

03
Repair

A deterministic backstop keeps only edges that point strictly backward, so the stored graph is always a clean DAG. Roots with no prerequisites start UNLOCKED.

04

Completing an unlocked milestone marks it DONE and cascades unlocks to every dependent whose prerequisites are now satisfied. When all are DONE, the goal is ACHIEVED.
